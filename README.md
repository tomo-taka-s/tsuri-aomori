# 青森 釣り潮見（PWA）

青森県内の港・釣り場（24か所）ごとに、潮回り・満潮干潮・潮位グラフ・天気・風・波・水温・魚種別の釣れやすい時間帯を時系列で表示するスマホ向けWebアプリです。
サーバー側の処理はなく、静的ファイルだけで動きます。潮の計算は端末内で行うので電波がなくても動き、天気・波・水温はオンライン時に取得して、取れないときは最後の値を表示します。

対象魚種: アジ・サバ・イワシ（サビキ）／ヒラメ／カレイ／根魚（ソイ・メバル・アイナメ）／クロダイ／イカ（アオリイカ・コウイカ）／スズキ／総合

## 公開のしかた（どれか1つ）

### A. Cloudflare Pages（いちばん簡単・無料）
1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → 「Upload assets」
2. このフォルダの中身をそのままドラッグ＆ドロップ（フォルダごとのzipでも可）
3. 発行されたURL（https://〜.pages.dev）をスマホで開く

### B. Netlify Drop（登録不要に近い）
1. https://app.netlify.com/drop を開き、このフォルダをドラッグ＆ドロップ
2. 発行されたURLをスマホで開く

### C. GitHub Pages
1. 新しいリポジトリを作り、このフォルダの中身をアップロード
2. Settings → Pages → Branch: main / (root) → Save
3. https://ユーザー名.github.io/リポジトリ名/ をスマホで開く

※ HTTPS で公開されていることが、ホーム画面に追加（PWA）できる条件です（上の3つは自動でHTTPSになります）。

## スマホに入れる
- iPhone: Safariでそのページを開く → 共有ボタン → 「ホーム画面に追加」
- Android: Chromeで開く → メニュー → 「アプリをインストール」（画面内にインストールボタンも出ます）

## 中身
| ファイル | 役割 |
|---|---|
| index.html / style.css / app.js | 画面 |
| tide.js | 潮位（調和定数）・月齢・日の出日の入り・時合いの計算 |
| weather.js | 天気・風・波・水温の取得（Open-Meteo） |
| species.js | 魚種ごとの時期・適水温・地形・風波のルール表と採点（ここを直せば★が変わる） |
| spots.js | 釣り場の一覧（地形 hab・波の受けやすさ exp もここ） |
| sw.js / manifest.webmanifest / icons/ | オフライン対応・ホーム画面アイコン |

## 釣り場を追加するには
`spots.js` に1行足します。`st` には使う気象庁観測点を指定します（大間 OMA／下北 SHI／大湊 OMI／青森 AOM／浅虫 ASA／竜飛 TAP／むつ小川原 OGW／八戸港 HAC）。
`k`（潮位の振幅倍率）と `dt`（時刻のずれ・分）を入れると、現地の実測に合わせて補正できます。

## 精度と出典（潮位）
- 潮位は気象庁の調和定数から端末内で計算しています。主要4分潮（M2・S2・K1・O1）に、季節変動（Sa・Ssa）と主な小分潮を加えています。
- 気象庁の遅角は、標準時の子午線（東経135度）ではなく**各地点の経度の現地時が基準**です。旧版はこれを考慮しておらず、満干潮が約1時間ずれる原因でした（v7で修正）。
- 小分潮と季節変動は、気象庁が60分潮を公表している「下北」の値を使い、他の港は主要4分潮との比（振幅比・位相差）で同じ関係として補っています（推定）。
- 検証（気象庁の推算毎時潮位との差。誤差は2〜3cm程度、最大6cm）:
  - 八戸港 2026年1月・4月・7月・10月（各5〜7日）: RMSE 3.4 / 1.9 / 1.8 / 3.4 cm、最大6cm（旧版は 9〜14 cm、最大35cm）
  - 下北 2026年10月: RMSE 0.8 cm
  - 青森 2024年1・2月: RMSE 4.2 cm（旧版 7.9 cm）
  - 大間・大湊・浅虫・竜飛・むつ小川原は気象庁の毎時値と比べていません。日本海側（十三湖・鰺ヶ沢・深浦）は竜飛の定数の流用で参考値です。
- 気象庁の推算値と同じく、台風・低気圧・強風による潮位の上下（気象潮）は含みません。画面の「いま」に、気圧からの目安（1hPaあたり約1cm）だけ出しています。
- 実際の潮と合わないときは、グラフの下の「微調整」で潮の時刻（±分）と潮位（±cm）を釣り場ごとに合わせて保存できます。
- 「釣れやすさ」は目安です（潮の動き・上げ3分/下げ7分・満干潮前後・朝夕マズメ・潮回り・時期・水温・風波）。

## 天気・波・水温について（重要）
- データ元は Open-Meteo の無料API（天気・風）と Marine API（波・海面水温）です。個人利用の範囲を想定した無料枠なので、公開して多くの人が使う場合や商用にする場合は、利用条件（https://open-meteo.com/en/terms ）を確認してください。
- 波と水温は広域の海況モデルの値です。湾内・港の奥では取れない／実際と違うことがあり、取れない項目は「データなし」と表示し、判定には入れません。
- 作成時の環境からは外部APIに接続できなかったため、天気・波・水温は**実際のAPIでは未検証**です（模擬の応答で表示・荒天判定・取得失敗時の動作だけ確認済み）。公開後、実機で値が出るかをまず確認してください。
- 魚種ごとの「時期」「適水温」「向いている地形」は一般的な知識から置いた**初期値**で、青森の釣果データで検証していません。合わない魚種・時期は `species.js` の表を直してください。
- 風向きによる向き不向き（その港に吹き込む風かどうか）は入っていません。

## 画面の構成（v9）
上から「7日間の見通し → 狙う魚 → ひと目カード（その日の％・★・一言評価、荒天注意、ベストの時間帯、潮と日の出入り）→ 潮位グラフ → 天気・風・波・水温 → 時系列（すべて／★3以上／日中のみ）→ 魚種別の見通し → 月のベスト3」の順です。

## 月のベスト3
選んでいる釣り場・魚種で、その月の「狙い目の日」上位3日を出します（‹ › で月を切り替え、日をタップするとその日の詳細へ）。日ごとの比較は潮・月齢・時期・時間帯で行い、天気・波は予報のある約7日先までなので、荒天の予報が出た日だけ候補から外します。過ぎた日は含めません。

## 更新したのに古い画面が出るとき
このアプリは電波がなくても開けるよう、ファイルを端末に保存します。ファイルを置き換えて公開し直したあと、**最初に開いた画面は古い版のことがあります**。一度アプリを閉じて開き直す（または引っぱって再読み込み）と新しくなります。画面の一番下に「アプリの版：v9」と出るので、今どの版が動いているか確認できます。v8以降（現在はv9）は、新しい版が来ると画面下に「新しい版があります［更新する］」と出ます。
